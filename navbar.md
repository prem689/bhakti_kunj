# PREMIUM CINEMATIC NAVBAR — COMPLETE UI/UX DESCRIPTION

# NAVBAR PURPOSE

The navbar should NOT feel like:

* traditional corporate navbar
* wordpress menu
* normal real estate website

The navbar should feel:

* luxury
* futuristic
* cinematic
* minimal
* premium
* floating
* architectural

It should blend naturally into the hero section.

---

# NAVBAR POSITION

## TYPE

Fixed navbar.

Always visible while scrolling.

---

# INITIAL STATE (TOP OF PAGE)

Navbar background:

* fully transparent

Reason:
To merge seamlessly with cinematic hero background image.

Only text and buttons visible.

---

# AFTER SCROLL

Navbar transforms into:

* dark glassmorphism bar
* blur background
* semi-transparent black/green overlay

Example:
background:
rgba(5, 10, 8, 0.65)

backdrop-filter:
blur(16px)

Border:
1px solid rgba(255,255,255,0.08)

Shadow:
very soft luxury shadow.

Transition:
smooth 0.4s ease.
